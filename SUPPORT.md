# Support

sdlc-squad is a free, MIT-licensed, Markdown-only kit maintained by one person, best effort.

- **A bug or a broken artifact shape** — open an issue with the skill name, the input shape, and
  what the artifact got wrong against its output schema.
- **A new skill idea** — open an issue with: role, input, output contract, import target. See
  [`CONTRIBUTING.md`](CONTRIBUTING.md).
- **Security** — private vulnerability reporting only; see [`SECURITY.md`](SECURITY.md).
- **How to use the kit** — start at [`USER-GUIDE.md`](USER-GUIDE.md); the contract is
  [`WHAT-THIS-IS.md`](WHAT-THIS-IS.md).

The kit is offline by design: there is no hosted service, no support SLA, and no account to
recover. If a chat run misbehaves, the fix lives in a Markdown file here, and the same file fixed
in your copy fixes every future run.
